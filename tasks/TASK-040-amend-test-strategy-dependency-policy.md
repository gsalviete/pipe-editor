# [DOC] Amend test strategy and dependency policy (Phase 6)

## What this card solves

Phase 6 (AR-29, AR-31) closes the evidence gap: status labels and green suites were read as proof of properties they never exercised. Before tests and dependencies change, the rules for what counts as evidence must be written down:
- what a "pure" test must replace;
- how Docker suites prove daemon readiness;
- that test files are typechecked;
- that generator tests validate provider or build validity;
- that golden fixtures must be runnable;
- how advisories are triaged, and where accepted exceptions are recorded.

The closure bar (review §8) becomes part of the test strategy, so it outlives this product.
