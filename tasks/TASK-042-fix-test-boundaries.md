# [DX] Fix test boundaries that overstate guarantees (AR-31)

## What this card solves

Several tests pass while proving less than their names say:
- The "pure" executor suite mocks `docker-client` but not `workspace-visibility`, so it still launches a real Docker probe. That's why the full run timed out once.
- Docker suites decide whether to run by CLI presence, not daemon readiness.
- The CI step "Typecheck source and tests" doesn't typecheck frontend tests, because `tsconfig.json` excludes spec files.
- The npm golden IR still carries `pnpm lint`/`pnpm test`, so the fixture isn't runnable as named.

Phases 1–5 already replaced the misleading provenance and order tests at their boundaries. This card fixes the remaining infrastructure so that the gate means what it says, following the TASK-040 amendments.
