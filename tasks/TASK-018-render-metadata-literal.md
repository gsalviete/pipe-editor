# [FIX] Render generated metadata as literal text (AR-10)

## What this card solves

Generators sanitize some interpolated values but not others:
- the single-service Dockerfile sanitizes `project.name`, but puts runtime and package-manager versions straight into a comment, and the runtime version into `FROM`;
- the Vite template puts `service.name` into a comment unsanitized;
- the workspace GitLab header puts `plan.name` in raw.

A newline in any of them adds a new Dockerfile instruction or YAML key. Review probe R10 does this through a Vite service name while **every bundle check passes**.

TASK-015 makes versions validate at the IR boundary. This card is defense in depth at the output: every generated comment goes through `sanitizeForComment`, every YAML value is emitted as data (`yamlScalar`/`dumpYaml`), and `FROM` uses only a validated version. `GUIDELINES.md` § Security requires generated comments to pass through `sanitizeForComment`.
