# [FIX] Import conditional GitHub work as disabled (AR-21)

## What this card solves

The GitHub Actions importer ignores job and step `if:`, `shell:`, `defaults.run.working-directory` and service configuration, usually without a warning. A step with `if: false`, or one that runs only on tags, becomes enabled local shell work that the user can run with one click. That breaks CIIMPORT-NFR-003 ("lossy, and loud").

The product doc decided that conditional or manual jobs and steps import **disabled**, each with a specific warning, and the user can re-enable them. `working-directory` (step and `defaults.run`) maps to the IR step's `workingDir`. `shell:` maps where the IR can represent it and warns otherwise. Services warn. No condition is evaluated, because full CI simulation is a non-goal.
