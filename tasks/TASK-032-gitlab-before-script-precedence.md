# [FIX] Match GitLab before_script precedence on import (AR-21)

## What this card solves

The GitLab importer concatenates `default.before_script` and the job's `before_script`. In GitLab, a job's own `before_script` **replaces** the default. A top-level (legacy) `before_script` is ignored completely. Review probe R14 confirms both. The existing criterion CIIMPORT-AC-002 expects the wrong behavior, so TASK-024 supersedes it and this card changes code and test together.

Conditional GitLab work follows the same product decision as GitHub: `rules:`/`only:`/`except:`/`when: manual` jobs import **disabled** with a specific warning.
