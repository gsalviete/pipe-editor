# [FIX] Budget workspace copies; remove interrupted ones (AR-25, AR-26)

## What this card solves

Every run copies the whole project into a temp directory with `cpSync`, nested `node_modules` included (by spec). Nothing limits the bytes or file count. And if the copy fails partway (disk full, permission error, abort), no cleanup exists yet, because `materializeWorkspace` only returns its `cleanup` closure after the copy succeeds. The half-written temp directory stays behind.

This card enforces the TASK-034 byte and file budgets during the copy. It also makes the copy clean up after itself on any failure: the temp directory is created first, and it is removed on every exit path. Exceeding the budget produces the refusal result TASK-034 specifies, before any container starts.

## Implementation plan

- `backend/src/modules/executor/workspace.ts:18-42`:
  - Wrap the copy in `try/catch` that `rmSync(tmp, …)` on failure, then rethrow a typed error from `executor/errors.ts`.
  - Count files and bytes in the `filter` callback (`:25-32`, which already visits every entry) and throw a budget error once a limit is exceeded. `lstat` inside the filter gives sizes without following links.
  - Accept an `AbortSignal`, and check it in the filter.
- `backend/src/modules/executor/execute.ts:91`: pass `opts.signal` and map the budget error to the specified result.
- Keep the TASK-002 marker and copy-symlink behavior intact.
- Validation: `pnpm --dir backend test -- executor`, then `pnpm check`.
- Size: ~90 production lines.
- Out of scope: container stop/removal (TASK-037), and async copying (a §7 follow-up).

## Attention points

- `cpSync`'s filter is synchronous, so abort is only checked between entries. That's acceptable. Say so in the spec note and don't claim instant abort.
- `EXEC_KEEP_WORKSPACE` (`:38`) still keeps **successful** copies for debugging. It must not keep failed partial copies.
- ❌ Don't pre-walk the tree in a separate pass to measure it. That doubles the I/O and races with the copy.

## Observability

- `console.warn` when a copy is refused for budget (the limit that tripped and the counted value; no paths outside the project).
