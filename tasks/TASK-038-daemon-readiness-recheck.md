# [FIX] Probe daemon readiness and allow re-check (AR-27)

## What this card solves

The backend reports Docker as available when `docker --version` succeeds. That proves the CLI is installed, not that the daemon is running, so a stopped daemon shows as available and the run fails later. The run panel asks once, when it mounts. If Docker was off, Run stays disabled with "start Docker" even after the user starts it, because nothing re-checks.

This card changes the availability check to query the daemon (`docker version --format` with a server field, or `docker info`) with a timeout, and adds a minimal "Check again" control next to the disabled reason. That control is one of the minimum UI states the product doc allows.
