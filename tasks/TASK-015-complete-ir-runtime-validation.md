# [FIX] Complete runtime validation of IR fields (AR-30, AR-10)

## What this card solves

`validate()` is the IR's runtime contract, but it doesn't check every field that consumers read:
- **Triggers** aren't validated at all. `branches: "main"` passes and is exported as the wrong shape (review probe R09).
- **Metadata** only has to be a non-null object.
- **Runtime and package-manager versions** accept any string. R03 inserts a new Dockerfile `RUN` line through a version value that passes validation.

This card makes `validate()` check every consumed field against the TASK-014 amendments: trigger kind and branches as an array of safe strings, the metadata shape, and version syntax and range. Downstream generators can then trust validated input, and a bad document is rejected at the boundary instead of producing broken artifacts.
