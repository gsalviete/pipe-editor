# [FIX] Contain CI-file reads in discovery and import (AR-02, AR-03)

## What this card solves

Two readers remain outside the primitive that TASK-003 introduces. First, discovery inventories `.github/workflows` by listing whatever that directory resolves to, including a directory symlink that points outside the workspace. Second, the CI-file import endpoint checks `statSync().size` and then calls `readFileSync`, so a FIFO at `.github/workflows/ci.yml` blocks the process, and a file that grows after the check escapes the 512 KiB limit.

This card routes both through the contained, bounded reader, and makes the workflow inventory refuse a workflows directory that resolves outside the project. The import endpoint keeps its current error envelope codes, so clients see no contract change except the new refusals.
