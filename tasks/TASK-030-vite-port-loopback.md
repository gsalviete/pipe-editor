# [FIX] Consistent Vite port; loopback-only ports (AR-20, AR-32)

## What this card solves

**AR-20:** the studio lets the user edit a Vite service's container port. Compose uses the new value, but nginx and the health check stay fixed at 80, so `3000:8080` is generated next to `listen 80` and every bundle check passes (review probe R10). The service is unreachable.

**AR-32:** generated Compose ports are `hostPort:containerPort` with no host IP, so Docker publishes the user's development app on **all interfaces**, reachable from the LAN. The editor's own Compose file binds to `127.0.0.1`.

The product doc decided: render the edited port into nginx `listen`, `EXPOSE`, Compose and the health check, and always bind generated ports to `127.0.0.1`, with a comment explaining how to widen exposure by hand. No new UI control.

## Implementation plan

- `backend/src/modules/workspace-bundle/generate.ts`:
  - `:162` `EXPOSE 80` becomes `EXPOSE ${containerPort}`;
  - `:170` `listen 80;` becomes `listen ${containerPort};`;
  - `:210` the healthcheck URL uses the container port;
  - `:206` `ports: ['127.0.0.1:${hostPort}:${containerPort}']`;
  - add a comment in the Compose header about binding (the Compose writer is `composeDocument`).
- `containerPort` is already validated as an integer from 1 to 65535 (`workspace-bundle/validate.ts:74-76`). Interpolating a validated number is safe.
- nginx as non-root can't bind ports below 1024 in some images, and `nginx:alpine` runs as root by default. State the chosen assumption in the Dockerfile comment.
- Frontend: no change. The field at `frontend/src/editor/WorkspaceStudio.tsx:329-331` keeps working (the product doc decision).
- Validation: `pnpm --dir backend test -- workspace-bundle`, then `pnpm check`.
- Size: ~70 production lines.

## Attention points

- Behavior change: users who reached generated services from other devices lose that by default. It is an intentional security default, and the comment explains the opt-out.
- The bundle's own port checks must verify the full mapping, not substrings.
