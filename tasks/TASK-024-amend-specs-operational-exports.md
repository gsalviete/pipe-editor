# [DOC] Amend specs for operational exports and import (Phase 4)

## What this card solves

Phase 4 (AR-15 to AR-22, AR-32) makes exported artifacts work outside the tool. Several current criteria encode the wrong behavior:
- **CIEXPORT-FR-011** makes a lockfile-keyed cache the handoff between GitLab jobs, but a cache is best-effort by design;
- **CIIMPORT-AC-002** expects default and job `before_script` to be **concatenated**, while GitLab has the job's value override the default;
- **CIIMPORT-NFR-003** ("lossy, and loud") has no per-construct behavior, so `if:` conditions disappear silently.

The product doc made the decisions: artifacts + `needs` for GitLab, conditional work imported **disabled** with a warning, the edited Vite port rendered consistently, loopback-only publishing, and offline schema validation as the gate. This card turns them into criteria, and settles two open questions: what to do with GitHub trigger features GitLab can't express, and which offline schema tools to use.
